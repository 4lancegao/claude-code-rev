## 核心数据流

```
┌──────────┐    ┌───────────┐    ┌───────────────┐    ┌──────────────┐
│ 用户输入  │───►│ 命令路由   │───►│  查询引擎循环   │───►│  Claude API   │
│ (stdin)  │    │           │    │               │    │  (流式响应)   │
└──────────┘    │ 斜杠命令?  │    │ 构建提示词     │    └──────┬───────┘
                │  ├─ Yes ──►│ 收集上下文      │           │
                │  └─ No  ──►│ 调用 API        │◄──────────┘
                └───────────┘ │               │
                              │ 解析响应       │
                              │  ├─ 文本 ────────────────────►  渲染到终端
                              │  └─ 工具调用 ──►│
                              │               │
                              │ ┌─────────────▼──────────┐
                              │ │    工具执行 & 权限检查    │
                              │ │                        │
                              │ │  权限通过? ──► 执行工具  │
                              │ │  权限拒绝? ──► 请求用户  │
                              │ │                        │
                              │ │  收集工具结果            │
                              │ └────────────┬───────────┘
                              │              │
                              │ Token超限? ──► 自动压缩
                              │              │
                              │ 还有工具调用? ─► 继续循环
                              │              │
                              │ 完成 ─────────► 等待下一轮输入
                              └───────────────┘
```
